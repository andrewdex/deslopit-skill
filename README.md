# deslopit

Agent skills pack. Clean AI slop from human writing before it ships.

## Skills

- **deslopit** (`skills/deslopit/`) — strip filler, buzzwords, and LLM tells from posts, emails, copy, and replies so text sounds like a person wrote it.

## Install

```bash
npx skills add andrewdex/deslopit-skill
```

Works with any agent that supports the agent-skills format (Claude Code, Codex, Cursor, Gemini CLI, Hermes, and more).
